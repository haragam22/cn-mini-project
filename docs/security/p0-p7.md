# Security review — full project P0–P7 (2026-11-10)
security-breaker run on P0–P7 (first run on the project). 6 high, 10 medium/low. Repro inputs were
in the job scratch dir; every fixed finding has a regression test in
`tests/test_security_hardening.py` (or the named test).

| # | Sev | Finding | Status |
|---|---|---|---|
| F1 | high | Rich/Textual markup in user strings (`[/]`) crashed CLI and TUI with a traceback | **fixed**: CLI console `markup=False`, TUI `Static(markup=False)` + `Text` cells/labels |
| F2 | high | duplicate link pairs / site ids with `--` → duplicate IPs (exit 0), Global crashed | **fixed**: INPUT.LINK_DUPLICATE, INPUT.SITE_ID_RESERVED (`--`) |
| F3 | high | site id `cloud-vgw` clashed with the generated cloud device | **fixed**: reserved ids cloud-vgw, inet-sw, evpl-carrier, cloud, internet, carrier, infra |
| F4 | high | root overlapping the lab Internet block 203.0.113.0/24 accepted → duplicate IPs | **fixed**: ADDR.OVERLAP for root/reserved vs `design.yaml public_block` |
| F5 | high | deeply nested / non-UTF-8 JSON → traceback, exit 1 | **fixed**: INPUT.FILE for ValueError/UnicodeDecodeError/RecursionError (CLI + TUI) |
| F6 | high | unbounded counts + per-device Jinja recompile → multi-minute hangs | **fixed**: caps sites ≤ 64, links ≤ 256, segments ≤ 24/site, reserved ≤ 64, hosts ≤ 2^24; cached Jinja env. Worst allowed input: 0.3 s |
| F7 | medium | segment names normalising to the same VLAN name | **fixed**: `vlan_names` de-duplicates |
| F8 | medium | VLAN names > 32 chars | **fixed**: capped at 32 |
| F9 | medium | CSV formula injection via site column / tab prefix | **fixed**: `_csv_safe` on site + name, tab/CR included |
| F10 | medium | terminal escape sequences in names | **fixed**: names printable ASCII only (≤ 64) |
| F11 | medium | dnspython 2.8.0 CVE-2026-114605 (transitive, no reachable path) | backlog |
| F12 | low | `Infinity` accepted for floats | **fixed**: `allow_inf_nan=False` |
| F13 | low | newlines in names broke Markdown structure | **fixed** with F10 |
| F14 | low | ZIP excludes secrets.txt but configs inside carry the secrets; one enable/admin pair for all devices | backlog |
| F15 | low | float arithmetic in errors for huge host counts | **fixed** by the hosts cap |
| F16 | low | duplicate JSON keys silently resolved | **fixed**: duplicate keys → INPUT.FILE |

Tried, not broken: IOS config injection via names, path traversal, Mermaid injection, case/truncation
hostname collisions, NaN, secrets randomness/permissions, git history leaks, missing/dir `--input`.
Open critical/high: **0**.
